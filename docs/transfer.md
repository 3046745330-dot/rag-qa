# 转专业与辅修管理办法

转专业与辅修管理办法。

**转专业**
申请时间：大一学年末（第二学期期末）。
申请条件：
1. 第一学年无不及格课程；
2. 平均绩点不低于 2.5；
3. 无违纪记录。

流程：个人申请 → 转出学院同意 → 转入学院考核 → 教务处审批 → 公示。
考核方式由转入学院确定，一般为笔试 + 面试。
接收名额一般为该专业当年招生数的 10%。

**辅修**
辅修专业学制 2 年，需修满约 30 学分。
报名时间：大二上学期。
条件：主修专业无不及格课程，绩点不低于 2.0。
辅修成绩单独记载，不影响主修 GPA。
完成辅修要求的，颁发辅修证书。

**双学位**
仅限部分专业开设。要求更严格，需修满约 50 学分，
且主修专业绩点不低于 3.0。
