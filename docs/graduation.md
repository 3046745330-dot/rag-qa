# 毕业与学位授予要求

毕业与学位授予要求如下。

**学分要求**
本科总学分不低于 160 学分，其中：
- 通识必修课：约 45 学分
- 专业必修课：约 65 学分
- 专业选修课：不低于 30 学分
- 实践环节：约 20 学分（含毕业设计 8 学分）

**毕业设计**
毕业设计安排在第八学期，为期约 16 周。
需完成开题、中期检查、答辩三个环节。
答辩前需提交查重报告，重复率不得高于 30%。

**学位授予条件**
1. 修满培养方案规定的全部学分；
2. 平均学分绩点（GPA）不低于 2.0；
3. 通过毕业设计答辩；
4. 无留校察看及以上处分记录。

**关于学位英语**
自 2024 级起，不再将学位英语考试成绩作为学位授予的硬性条件，
但需通过学校组织的英语水平测试。

**结业与延毕**
未修满学分者先按结业处理，可在两年内回校补修，
补满后换发毕业证书。超过两年未修满的，作永久结业处理。
