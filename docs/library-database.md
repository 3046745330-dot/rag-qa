# 电子资源与数据库使用

图书馆订购的中外文数据库。

**中文数据库**：中国知网（CNKI）、万方数据、维普期刊、读秀学术搜索、
超星数字图书馆。

**外文数据库**：IEEE Xplore、ACM Digital Library、Springer Link、
ScienceDirect、Web of Science、EI Compendex。

**访问方式**：
1. 校园网内直接访问，无需登录。
2. 校外访问需通过 VPN 或 CARSI 认证。VPN 账号与校园网账号一致。

**使用规范**：
严禁使用下载工具批量下载文献。系统检测到异常下载行为将自动
冻结该账号，需到图书馆办公室说明情况后解封。
单日下载量上限为 200 篇。
