# 宿舍设施报修流程

宿舍设施报修流程。

**报修渠道**：
1. 微信小程序"后勤服务"→ 在线报修 → 选择楼栋房间 → 描述问题 → 上传照片
2. 拨打后勤维修电话（工作日 08:00-17:30）
3. 到宿舍楼一楼值班室填写纸质报修单

**响应时限**：
- 紧急类（漏水、跳闸、门锁损坏）：2 小时内上门
- 一般类（水龙头滴水、灯管闪烁）：24 小时内
- 非紧急类（墙面污损、家具松动）：3 个工作日内

**费用**：
自然损耗免费维修。人为损坏按材料成本收费，费用从宿舍押金中扣除。
空调、热水器属于学校资产，任何情况下不得自行拆装。

**常见问题自助处理**：
- 跳闸：检查是否有大功率电器，拔掉后到配电箱复位开关
- 停水：先确认是否全楼停水，可查看后勤公众号通知
