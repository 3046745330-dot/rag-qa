# 学生宿舍管理规定

学生宿舍管理规定。

**作息**
宿舍楼大门 23:00 关闭，次日 06:00 开启。晚归需登记，累计晚归 3 次
通报所在学院。因实习、实验等原因需晚归的，提前向宿管报备。

**卫生检查**
每周三下午进行卫生检查，评分结果计入文明宿舍评比。
卫生不合格的宿舍需在 24 小时内整改。

**访客**
访客需在门卫处登记，凭有效证件换取临时出入证。
访客时间为 08:00-21:00，不得留宿。

**调换宿舍**
原则上不允许调换。确有特殊原因（如身体原因、专业调整）的，
需本人申请、双方辅导员同意、宿管中心审批。
每学期集中受理一次，一般在开学后两周内。

**退宿**
毕业、休学、转学需办理退宿手续，交回钥匙和空调遥控器。
物品需在 3 日内清空，逾期视为放弃。
