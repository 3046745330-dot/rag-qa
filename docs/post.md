# 快递与邮政服务

快递与邮政服务。

**快递点**
学校设有一个快递综合服务中心，位于东门内 50 米。
入驻快递：顺丰、京东、中通、圆通、韵达、申通、邮政 EMS。
营业时间：08:00-20:00（周末 09:00-19:00）。

**取件**
凭取件码到对应快递公司的货架取件。
大件包裹需到人工窗口。
超过 3 天未取的包裹将被退回。

**寄件**
各快递公司在服务中心设有寄件窗口，可直接寄送。
学生寄件享 9 折优惠（需出示学生证）。

**邮政服务**
校门口设有邮政信筒和邮政代办点。
信件、挂号信、汇款等业务在代办点办理。
EMS 特快专递可在代办点或服务中心寄出。

**注意事项**
贵重物品建议选择顺丰或京东。寄件前确认包装完好。
丢件理赔按各快递公司标准执行，学校不承担连带责任。
