# 食堂消费与校园卡充值

食堂消费与校园卡充值。

**消费方式**
所有食堂档口均配备 POS 机，支持校园卡刷卡消费。
第二食堂、第三食堂部分档口支持微信/支付宝扫码。

**充值渠道**
1. 校园卡 APP（推荐）：实时到账，支持微信/支付宝/银行卡
2. 自助充值机：分布在各食堂门口、图书馆一楼、宿舍区
3. 校园卡服务中心：工作日 08:30-17:00

**余额与消费限额**
单笔消费上限 50 元，单日累计上限 200 元。
超过限额需在 APP 中调整或到服务中心办理。
余额低于 10 元时 POS 机会提示，低于 0 元无法消费。

**挂失与解挂**
通过 APP 或服务中心挂失。挂失后 24 小时内消费损失由持卡人承担。
找到卡片可解挂，解挂后原卡继续使用。

**补贴发放**
家庭经济困难学生每月可获 100-300 元餐费补贴，
直接打入校园卡，仅限食堂消费，不可提现。
