# 选课管理办法

选课管理办法。

**选课时间**
每学期期末进行下学期选课，一般持续 5 天。
开学后第一周为补退选期，可调整课程。

**选课方式**
登录教务系统 → 选课 → 按课程类别筛选。选课采用"志愿 + 抽签"制：
首轮不限容量，系统按志愿优先度抽签；次轮先到先得。

**学分限制**
每学期选课学分不低于 15 学分，不高于 30 学分。
超出上限需院系审批。

**退课**
退课在补退选期内办理。逾期退课记为缺考。
无故缺考且未退课的，该课程成绩记 0 分。

**重修**
课程不及格需重修。重修不单独开班，随下一年级正常班级修读。
重修成绩按实际分数记载，并标注"重修"字样。
