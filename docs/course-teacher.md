# 教师教学与答疑规范

教师教学与答疑规范。

**答疑安排**
每门课程每周至少安排 1 次集中答疑，时间地点由任课教师公布。
答疑可通过线下、线上（课程群）两种形式进行。

**作业布置与批改**
专业核心课程每学期布置作业不少于 4 次，每次批改后 1 周内反馈。
作业成绩占总评的 30%。

**调课与代课**
教师因公因私需调课的，须提前 3 个工作日报教务处审批，
并通知学生。每学期调课不得超过 3 次。

**学生评教**
每学期末学生对任课教师进行网上评教，评教结果与教师考核挂钩。
未完成评教的学生不能查询本学期成绩。

**联系方式**
教师应在课程大纲中公布邮箱或办公地点，方便学生联系。
