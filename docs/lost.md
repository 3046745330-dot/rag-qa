# 失物招领与物品遗失处理

失物招领与物品遗失处理。

**失物招领点**
1. 保卫处值班室（主楼一层）：接收贵重物品、证件、钱包
2. 各食堂服务台：接收餐具外的遗留物品
3. 图书馆总服务台：接收馆内遗失物
4. 教学楼值班室：接收教室遗失物

**登记与认领**
拾获物品请交至任一失物招领点并登记。
认领需出示学生证并说明物品特征，贵重物品需登记签字。

**保管期限**
- 证件类：6 个月，逾期移交派出所
- 电子设备：6 个月，逾期公开拍卖或捐赠
- 其他物品：3 个月，逾期统一处理

**校园卡遗失**
单独流程：先 APP 挂失，再到校园卡服务中心补办（工本费 20 元）。

**预防建议**
在电子设备上贴姓名和联系方式标签。
不要在图书馆、食堂用贵重物品占座。
