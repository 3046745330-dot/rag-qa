# 宿舍区网络与信号说明

宿舍区网络环境说明。

**有线网络**
每间宿舍配备 4 个网口（床位对应）。网线需自备。
接入需在校园网自助服务系统绑定 MAC 地址，绑定后即可上网。

**无线网络**
宿舍区覆盖 `CampusNet-Dorm` 信号。5GHz 频段速度更快但穿墙弱，
2.4GHz 覆盖好但易受干扰。

**常见故障**
- 无法连接：检查是否欠费、MAC 是否绑定
- 速度慢：晚 20:00-23:00 为高峰时段，属正常现象
- 频繁掉线：尝试更换信道，或联系网络中心

**移动信号**
宿舍楼内移动、联通、电信信号均有室内分布系统覆盖。
地下层（车库、储藏室）信号较弱。
