# 自助打印与复印服务

自助打印与复印服务。

**服务点**
- 图书馆五层：6 台自助一体机（打印/复印/扫描）
- 各教学楼一层：2 台
- 学生活动中心一层：2 台

**收费标准**
| 类型 | 黑白 | 彩色 |
|---|---|---|
| 单面 | 0.10 元/页 | 0.50 元/页 |
| 双面 | 0.16 元/页 | 0.90 元/页 |
| 复印 | 同上 | 同上 |
| 扫描 | 免费（存 U 盘） | — |

**使用方式**
刷校园卡或扫码登录 → 选择文件 → 设置参数 → 确认扣费 → 取件。
支持 U 盘、微信文件传输、云盘链接三种导入方式。

**注意事项**
打印前请预览，扣费后不支持退款。
卡纸时不要强行拉拽，按机器上的求助按钮。
余额不足 5 元无法发起打印任务。
