# 学生请假与考勤规定

学生请假与考勤规定。

**请假类型**
- 病假：需提供医院证明
- 事假：需说明具体事由，原则上不予批准超过 3 天
- 公假：参加学校组织活动的，由组织单位出具证明

**审批权限**
| 时长 | 审批人 |
|---|---|
| 1 天以内 | 辅导员 |
| 2-3 天 | 辅导员 + 班主任 |
| 4-7 天 | 学院分管领导 |
| 7 天以上 | 学生处 |

**考勤**
课堂考勤由任课教师负责。旷课累计达到课程学时 1/3，
取消该课程考试资格，成绩记不及格。

**离校**
请假离校需在辅导猫或学工系统报备行程。返校后及时销假。
未销假的，超出时间按旷课处理。

因病需长期休养的，可申请休学，休学期限一般为 1 年。
