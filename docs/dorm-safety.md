# 宿舍消防安全规定

宿舍消防安全规定（重要）。

**严禁事项**
1. 严禁使用热得快、电炉、电饭锅、电热毯等大功率电器。
2. 严禁私拉乱接电线、使用不合格插排。
3. 严禁在宿舍内吸烟、使用明火（含点蜡烛、焚香）。
4. 严禁在楼道、疏散通道堆放杂物或停放电动车。
5. 严禁将电动车电池带入宿舍充电。

**消防设施**
每层楼配置灭火器 2 具、消防栓 1 个，位置见楼层示意图。
宿舍内安装独立式烟感报警器，请勿遮挡或拆卸。

**应急疏散**
火警时从最近的安全出口撤离，不要乘坐电梯。
疏散路线图张贴在每层楼梯口。

**违规处理**
违反上述规定，视情节给予警告至记过处分；
造成事故的，从重处理并追究经济责任。
