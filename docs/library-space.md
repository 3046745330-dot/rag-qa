# 图书馆空间分布与服务

图书馆共 6 层，各层功能分布如下。

**一层**：总服务台、新书展示区、24 小时自习室、自助借还机。
**二层**：中文社科图书借阅区（A-K 类）。
**三层**：中文自然科学图书借阅区（N-Z 类）、外文图书区。
**四层**：期刊阅览室、报纸阅览室、过刊库。
**五层**：电子阅览室（80 台机位）、多媒体学习区。
**六层**：研讨间（12 间，需 3 人以上预约）、小组学习区。

**特色服务**：
- 文献传递：馆藏没有的文献可申请馆际互借，一般 3-5 个工作日。
- 学科馆员：每个学院对接一名学科馆员，可提供定题检索服务。
- 自助打印：五层提供自助打印、复印、扫描，黑白 0.1 元/页。
