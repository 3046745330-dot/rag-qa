# 实践教学环节要求

实践教学环节要求。

**实验课**
实验课缺席超过总学时 1/3，不得参加考核，成绩记不及格。
实验报告需独立完成，雷同者双方均按零分处理。

**课程设计**
为期 1-2 周，需提交设计报告和可运行的程序/实物。
课程设计单独计分，计入实践学分。

**实习**
包括认识实习和生产实习，累计不少于 8 周。
实习需提交实习单位鉴定表和实习报告。
自行联系实习单位的，需提前报院系备案。

**毕业设计**
第八学期进行，为期约 16 周。
答辩前需通过查重（重复率 ≤30%）和格式审查。
毕业设计成绩由指导教师评分（40%）、评阅教师评分（20%）、
答辩成绩（40%）三部分构成。

**学科竞赛**
参加省级以上学科竞赛获奖，可申请创新创业学分，
最多可替代 4 个专业选修学分。
