# 心理健康服务

心理健康教育与咨询中心。

**位置与时间**
位于学生活动中心三层，周一至周五 09:00-17:00。
咨询需提前预约。

**预约方式**
1. 心理健康中心公众号在线预约
2. 电话预约
3. 现场预约（工作日）

**服务内容**
- 个体咨询：每次 50 分钟，免费，每人每学期最多 8 次
- 团体辅导：主题包括人际交往、情绪管理、压力应对
- 心理测评：新生入学时统一进行，其他时间可申请
- 危机干预：24 小时热线，紧急情况可直接到中心

**保密原则**
咨询内容严格保密，不记入档案，不影响评优和就业。
例外：涉及自伤或伤害他人的风险时，会启动必要的干预程序。

**常见误区**
心理咨询不是"有病才去"。学业压力、人际困扰、情绪波动
都可以寻求帮助，这在大学里很常见。
