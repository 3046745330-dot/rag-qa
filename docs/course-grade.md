# 成绩考核与绩点计算

成绩考核与绩点计算办法。

**考核方式**
课程考核分考试和考查两种。考试课为百分制，考查课为五级制
（优秀、良好、中等、及格、不及格）。

**成绩构成**
一般由平时成绩（30%）和期末成绩（70%）组成。
具体比例由任课教师在课程大纲中明确。

**绩点换算**
| 百分制 | 绩点 |
|---|---|
| 90-100 | 4.0 |
| 85-89 | 3.7 |
| 82-84 | 3.3 |
| 78-81 | 3.0 |
| 75-77 | 2.7 |
| 72-74 | 2.3 |
| 68-71 | 2.0 |
| 64-67 | 1.5 |
| 60-63 | 1.0 |
| 60 以下 | 0 |

**平均绩点（GPA）**
GPA = Σ(课程绩点 × 课程学分) / Σ课程学分

**成绩复议**
对成绩有异议，可在成绩公布后 5 个工作日内向开课学院提交
书面复议申请，逾期不再受理。
