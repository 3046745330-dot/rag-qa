# 校园安全须知

校园安全须知。

**防火**
宿舍内严禁使用明火、大功率电器。离开宿舍请关闭电源。
发现火情立即拨打校内火警电话，并使用楼道灭火器初期扑救。
每层楼均配有灭火器和消防栓，请熟悉其位置。

**防盗**
离开宿舍锁好门窗，贵重物品不要放在显眼处。
图书馆、食堂等公共场所注意随身物品，不要用书包占座后离开。
自行车请停放在指定区域并上锁。

**防诈骗**
警惕冒充老师、客服、公检法的电话和短信。
凡是要求转账、提供验证码、点击陌生链接的，一律拒绝。
遇到可疑情况可拨打校园报警电话或咨询辅导员。

**夜间出行**
尽量避免深夜独自外出。校园内主要路段有监控和照明。
夜间可从校门保安处申请护送服务。

**突发事件**
遇到突发疾病、意外伤害，先拨打校医院急诊电话，
情况紧急可直接拨打 120 并同时通知辅导员。
