fix: 工具台脚本 + 恢复误删文件 + 去掉硬编码判分

三件事：

1. 恢复误删的两个脚本
   上一轮清理目录时误删了 看数据长什么样.py 和 读代码.py，
   而 tools.py 正好调用它们，导致菜单选项 1/2 报找不到文件。
   从 git 历史恢复，并存成 tools.py 期望的 ASCII 名
   （kan-shuju.py / du-daima.py），避免中文名加 bat 编码问题。

2. 新增 工具台.py（存为 tools.py）
   菜单式入口：看数据 / 查英文 / 跑验收 / 打开讲义。
   用 Python 写菜单而不是 bat：bat 在中文 Windows 上有编码问题
   （GBK 与 UTF-8 混用会乱码，实测变量被吃掉）。

3. 去掉脚本末尾的硬编码判分
   原来末尾写死「你答错了第 1、4 题」，每次运行都是同样判定，
   看第二遍会让人以为怎么还是错的。
   改成带提示的自测问题：让他自己答，再判。
